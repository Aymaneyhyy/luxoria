# LUXORIA - Frontend (React 19 & Vite 7)

## 🚀 Lancement

```bash
npm run dev
```

Le serveur de développement démarrera sur : **`http://127.0.0.1:5173`**

*(Note : L'application finale avec les données et l'authentification est servie via le backend Laravel sur **`http://127.0.0.1:8000`**)*

### Compilation pour la production :
```bash
npm run build
```
Les fichiers compilés sont générés directement dans `../backend/public/build/`.
