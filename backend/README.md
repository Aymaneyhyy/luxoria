# LUXORIA - Backend (Laravel 12)

## 🚀 Lancement

```bash
php artisan serve
```

Le serveur sera accessible sur : **`http://127.0.0.1:8000`**

### Commandes utiles :
```bash
# Effacer les caches
php artisan optimize:clear

# Migrer et réensemencer la base de données
php artisan migrate:fresh --seed
```
